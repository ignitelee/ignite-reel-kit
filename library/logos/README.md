# Extra brand logos

Real logos for brands IBs often mention that aren't in the Simple Icons library (`npm run logo -- <brand>`
searches both). Use them in reel.json as `"logo": "kit:<slug>"`, in a `glass` item or a `logo` pop.

Each logo is the brand's own (see `logos.json` "source"), a trademark of its owner: show it only when the video
names that brand, never in a way that suggests the brand endorses you. To add one: put the official file here
(square app icon, PNG or SVG, no scripts in SVGs) and add a line to `logos.json`.
