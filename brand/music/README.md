# Music

The kit ships with no music (music licences don't allow passing tracks on). Add your own:

1. Download tracks you're allowed to use in social videos, e.g. from the YouTube Audio Library or Pixabay Music
   (check each track's licence).
2. Drop MP3 or WAV files into the folder that matches the mood: `upbeat/`, `inspiring/`, `calm/`, `emotional/`.
3. That's it. When you pick a mood, the kit uses a track from that folder and sets the volume quietly under
   your voice automatically (about 18 dB under, the level IGNITE uses).

If a mood folder is empty, the reel is made without music and you'll be told.
